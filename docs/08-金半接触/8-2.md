## 8.2 整流接触与欧姆接触 :material-target: **考点**{: .md-tag }


### 整流接触（肖特基二极管） :material-target: **考点**{: .md-tag }

整流接触利用金半接触中**阻挡层**的整流特性，具有**单向导电性**。

形成条件：
- n型半导体：$W_m > W_s$（形成电子阻挡层）
- p型半导体：$W_m < W_s$（形成空穴阻挡层）

#### 平衡态 (V = 0)

以金属-n型半导体阻挡层接触为例：

- 半导体表面与体内电位之差（表面势）为 $V_D = -V_s$，其中 $V_s < 0$
- 由金属流向半导体的电子流 $N_{m \to s}$ 等于半导体流向金属的电子流 $N_{s \to m}$
- 净电流 $J = 0$


#### 反向偏置 (V < 0)

金属接负极，半导体接正极：

1. 系统不再平衡，费米能级不再统一
2. 阻挡层是高阻区，电压主要落在阻挡层上
3. 外加电场与内建电场方向**相同**，增强了内建电场的作用 → **势垒增高**
4. 金属一侧的势垒高度 $q\phi_{ns}$ 没有变化
5. 形成 $J_{s \to m}$ **反向电流**，由于金属势垒 $q\phi_{ns}$ 很高且不变，所以电流**很小且恒定**
6. 半导体到金属的电子流可以忽略不计 → **反向电流趋于饱和**

半导体势垒高度变为：$q(V_D - V)$（因为 $V < 0$，所以势垒升高）

#### 正向偏置 (V > 0)

金属接正极，半导体接负极：

1. 外加电场与内建电场方向**相反**，削弱了内建电场的作用 → **势垒降低**
2. 金属一侧的势垒高度 $q\phi_{ns}$ 没有变化
3. 形成 $J_{m \to s}$ **正向电流**，由于半导体势垒较低，所以**电流很大**
4. 正向偏压不断提高 → 势垒下降越多 → 正向电流越大 → 强烈依赖于外场

半导体势垒高度变为：$q(V_D - V)$（因为 $V > 0$，所以势垒降低）

#### 单向导电性（整流特性）

| | $V > 0$（金属接正，半导体接负） | $V < 0$（金属接负，半导体接正） |
|---|---|---|
| n型阻挡层（$W_m > W_s$） | **正向电流** | **反向电流** |
| p型阻挡层（$W_m < W_s$） | **反向电流** | **正向电流** |

> **注意：** 无论哪种阻挡层，**正向电流都对应于多子从半导体到金属**形成的电流。


### 热电子发射与扩散理论

#### 热电子发射理论

**适用范围：**
- n型阻挡层很薄，电子平均自由程 $l_n \gg$ 势垒宽度 $x_d$
- 势垒高度远大于 $k_0 T$
- 非简并半导体

**基本思路：**
- 薄阻挡层，起决定作用的是势垒**高度**而不是势垒宽度
- 电流的计算归结为跨越势垒的载流子数目
- 半导体内的电子浓度可视为常数

**伏安特性方程：**

$$
J = J_{sT} \left[ \exp\left( \frac{qV}{k_0 T} \right) - 1 \right]
$$

其中**有效理查逊常数**（饱和电流密度）：

$$
J_{sT} = A^* T^2 \exp\left( -\frac{q\phi_{ns}}{k_0 T} \right)
$$

- $A^*$ 为有效理查逊常数
- $J_{sT}$ 与外加电压无关，但强烈依赖于温度

**正向（$V > 0$）：** $J = J_{sT} \exp\left(\frac{qV}{k_0 T}\right)$，电流指数增长

**反向（$V < 0$）：** $J = -J_{sT}$，不依赖外压，趋于饱和

> Ge、Si、GaAs 有较大的平均自由程，符合热电子发射理论。

#### 扩散理论

**适用范围：**
- 势垒宽度远大于电子平均自由程：$l_n \ll x_d$
- 非简并半导体

**基本思路：**
- 电子通过势垒区要发生多次碰撞，存在漂移和扩散运动
- 当势垒高度远大于 $k_0 T$ 时，势垒区可近似为耗尽层

**伏安特性方程：**

$$
J = J_{sD} \left[ \exp\left( \frac{qV}{k_0 T} \right) - 1 \right]
$$

其中：

$$
J_{sD} = \frac{q^2 D_n N_c}{k_0 T} \left[ \frac{2q N_D}{\varepsilon_0 \varepsilon_r} (V_D - V) \right]^{1/2} \exp\left( -\frac{q\phi_{ns}}{k_0 T} \right)
$$

- $J_{sD}$ **与外加电压有关**（这是与热电子发射理论的关键区别）

**正向（$V > 0$）：** $J = J_{sD} \exp\left(\frac{qV}{k_0 T}\right)$

**反向（$V < 0$）：** $J = -J_{sD}$，随外压变化，**并不饱和**

#### 两种理论对比

| | 热电子发射理论 | 扩散理论 |
|---|---|---|
| **适用条件** | $x_d \ll l_n$，非简并半导体 | $l_n \ll x_d$，非简并半导体 |
| **电子运动** | 具有足够能量的电子越过势垒顶点 | 通过势垒区发生多次碰撞，存在漂移和扩散 |
| **饱和电流** | $J_{sT} = A^* T^2 \exp(-q\phi_{ns}/k_0T)$ | $J_{sD} \propto (V_D - V)^{1/2} \exp(-q\phi_{ns}/k_0T)$ |
| **反向特性** | 趋于饱和 | 不饱和，随外压变化 |

### 肖特基势垒二极管

**定义：** 利用金半接触整流特性制成的二极管称为肖特基势垒二极管（SBD）。

形成条件：$W_m > W_n$（n型）或 $W_m < W_p$（p型）。

#### 与pn结的相同点

都具有**单向导电性**，伏安特性均可用类似肖克利方程的形式描述：

$$
J = J_s \left[ \exp\left(\frac{qV}{k_0 T}\right) - 1 \right]
$$

#### 与pn结的不同点

| 特性 | pn结二极管 | 肖特基势垒二极管（SBD） |
|------|----------|---------------------|
| 载流子类型 | 少子/双极型器件 | **多子/单极型器件** |
| 电荷存储 | 有显著的**电荷存储效应**（低频） | **无电荷存储效应**（高频） |
| 正向导通电压 | 较高 | 较低（约 **0.3 V**） |
| 反向饱和电流 | 较小 | 相同势垒高度下，$J_{sD}$ 或 $J_{sT}$ 比 pn 结大得多 |
| 高频特性 | 较差 | **更好** |

**原因解释：**

- pn结正向电流为非平衡少子扩散形成的电流，有显著的电荷存储效应
- 肖特基势垒二极管的正向电流主要是**半导体多数载流子进入金属**形成的，是多子器件，无积累，因此高频特性更好

#### 肖特基二极管的新技术

- Si-SBD 的耐压 200V 已经是极限（Si 的绝缘击穿场强：0.3 MV/cm）
- SiC 拥有超过硅 **10 倍**的绝缘击穿场强（3 MV/cm），能保持实际应用特性且可耐高压
- ROHM 已实现 1200V SiC-SBD 量产


### 欧姆接触 :material-target: **考点**{: .md-tag }

**定义：** 电子通过金半接触时，能够不受势垒的阻挡，从一种材料输运到另一种材料，即其正反偏置下电流输运特征没有差别。

欧姆接触不产生明显的附加阻抗，接触上的压降远小于半导体压降，不影响器件的电流电压特性。

#### 基本特点

1. 伏安特性近似为**线性对称**
2. 接触引入的**电阻很小**（不产生明显的附加阻抗）
3. 不会明显改变**半导体内部平衡载流子浓度**

#### 形成欧姆接触的理想情况

- 形成**反阻挡层**
- n型半导体：$W_m < W_s$（电子反阻挡层，低阻）
- p型半导体：$W_m > W_s$（空穴反阻挡层，低阻）

#### 实际情况：隧道效应

由于表面态的存在，实际中常利用**隧道效应**来制备欧姆接触：

1. 当势垒很薄时，发生**隧道效应**
2. 隧道效应占主导地位时，形成欧姆接触
3. 隧穿的几率强烈依赖于势垒的**宽度**
4. 利用金属-**重掺杂**半导体接触的隧道效应

势垒宽度公式：

$$
d = \sqrt{\frac{2\varepsilon_0 \varepsilon_r (V_D - V)}{q N_D}}
$$

重掺杂条件：$N_D \geq 10^{19} \text{ cm}^{-3}$

> 重掺杂使得耗尽层极薄，电子可以通过隧道效应穿过势垒，从而实现近似线性的低电阻接触。这是实际半导体工艺中制备欧姆接触的主要方法。

### 小结

本节核心知识框架：

1. **整流接触**具有单向导电性，利用阻挡层实现
   - 正向偏置：势垒降低，电流大
   - 反向偏置：势垒升高，电流小且饱和
2. **热电子发射理论**适用于薄势垒（$x_d \ll l_n$），反向电流饱和
3. **扩散理论**适用于厚势垒（$l_n \ll x_d$），反向电流不饱和
4. **肖特基势垒二极管**是多子器件，高频特性好，正向导通电压低（~0.3V）
5. **欧姆接触**：理想情况利用反阻挡层；实际利用重掺杂 + 隧道效应
