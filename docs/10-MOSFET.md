# 第十章 MOSFET原理与基本结构

## 10.1 MOSFET的基本结构

### 10.1.1 MOSFET简介

**MOSFET**（Metal-Oxide-Semiconductor Field-Effect Transistor，金属-氧化物-半导体场效应晶体管）是现代集成电路中最核心的器件。以小米玄戒O1处理器为例，采用第二代3nm工艺，在109 mm²的面积上集成了**190亿个晶体管**，足见MOSFET在芯片中的基础地位。

#### 前置知识回顾

学习MOSFET之前，需要掌握两块基础知识：

**1. pn结**
- **平衡pn结**：能带图、接触电势差 $V_D$
- **非平衡pn结**：能带图、载流子分布、J-V特性（整流特性）

正向偏压时，势垒高度降低，势垒区变窄，电流指数增长；反向偏压时，势垒高度上升，势垒区变宽，电流几乎为零。这就是pn结的**整流特性**。

**2. MIS结构（金属-绝缘体-半导体）**
- **理想MIS结构**：定性和定量分析 $Q_s \sim V_s$、理想C-V曲线
- **实际MIS结构**：功函数对C-V曲线的平移、绝缘层中电荷对C-V曲线的平移、四种电荷的分布与产生

MIS结构的等效电路为绝缘层电容 $C_0$ 与半导体电容 $C_s$ 串联：

$$C = \frac{1}{\frac{1}{C_0} + \frac{1}{C_s}}$$

**表面电荷 $|Q_s|$ 随表面势 $V_s$ 的变化**可分为五个区域：
- **积累区**：$V_s < 0$，多子（空穴）在表面堆积
- **平带**：$V_s = 0$，能带不弯曲
- **耗尽区**：$V_s > 0$，多子被排走
- **弱反型区**：$V_s$ 继续增大，少子开始出现
- **强反型区**：$V_s \geq 2V_B$，表面少子浓度超过体内多子浓度，$|Q_s|$ 随 $V_s$ 呈指数增长 $\exp\left(\frac{q|V_s|}{2k_0T}\right)$

#### MIS与MOSFET的关系

MIS和MOSFET都受**表面场效应调控**，不同的是：
- MIS只做MOSFET的**控制回路**（纵向电场控制表面电导）
- MOSFET相当于在MIS基础上加一个**水平回路**，将表面调制效果反映到**水平回路电流变化**上

#### 表面电导调控效应

表面电导是指**平行于表面**的电导，取决于表面层内**载流子的数量和迁移率**，将随表面势变化。通过**垂直表面方向**的电场可以对表面电导进行控制——这正是MOSFET工作的物理基础。

> **小结**：MOSFET的本质是利用MIS结构的表面场效应，通过栅极电压控制半导体表面的载流子浓度（即表面电导），进而控制源漏之间的水平电流。理解MIS结构的C-V特性和表面电荷行为是学习MOSFET的关键前提。

## 10.2 MOSFET的工作原理

### 10.2.1 MOSFET的基本结构

MOSFET的全称为 **M**etal-**O**xide-**S**emiconductor **F**ield-**E**ffect **T**ransistor，按其早期器件的纵向结构命名。其基本结构如下（以N沟道为例）：

- **P型衬底**（Substrate）：作为器件的基体
- **两个N⁺区**：分别为**源极（Source, S）**和**漏极（Drain, D）**
- **绝缘氧化层**（SiO₂）：覆盖在源漏之间的沟道区域上方
- **栅极（Gate, G）**：位于氧化层上方的电极
- **衬底引出端（Body, B）**

> **注意**：现代MOSFET的栅电极不一定是金属（常用多晶硅），绝缘栅也不一定是氧化物（可用高k介质）。

### 10.2.2 MOSFET的工作原理（以理想NMOS为例）

MOSFET的核心机制是**表面电导调制效应**。以理想增强型NMOS为例，各端子的电位设置如下：
- **G（栅极）**：高电位，$V_G > 0$
- **S（源极）**：地电位
- **D（漏极）**：高电位
- **B（衬底）**：地电位，使源漏与衬底形成的pn结零偏或**反偏**（背对背结构，总有一个反偏）

#### 分阶段理解工作原理

**阶段一：$V_{GS} = 0$（初始状态）**

n⁺型的源区与漏区之间隔着p型区，且漏结反偏，故**无漏极电流**。器件处于关闭状态。

**阶段二：$0 < V_{GS} < V_T$（亚阈值状态）**

在栅极正电压的作用下，栅下P衬底中的空穴被排走，形成**耗尽区**。电子在栅氧化层下聚集，但此时电子浓度较低，**尚不足以形成导电沟道**。

**阶段三：$V_{GS} > V_T$（强反型，沟道形成）**

栅下的P型硅表面发生**强反型**（表面处的电子浓度（少子）等于衬底内部的空穴浓度（多子）），形成**n型反型层**，连通源、漏区的**N型沟道**。

其中条件为 $V_{GS} > 2\psi_B$（$\psi_B$ 为费米势）。

**阶段四：$V_T < V_{GS}$，$V_{DS} > 0$（产生漏极电流）**

电子向高电位的漏极运动，产生漏极电流。在 $V_{DS}$ 恒定的情况下，$V_{GS}$ 越大，沟道中电子越多，沟道电阻越小，漏极电流越大。

> **注意**：漏极pn结反偏，空间电荷区会叠加，靠近漏极的反型电子会减少。随着 $V_{DS}$ 增大，沟道**夹断**，并且夹断点不断左移。

#### 两个关键概念

**阈值电压（开启电压）$V_T$**：使栅下硅表面处开始发生**强反型**时的栅压。

**强反型**：当硅表面处的**少子浓度**达到或超过**体内平衡多子浓度**时，称表面发生强反型。

### 10.2.3 MOSFET的特点

1. **电场调节作用**：外加电场 $E$ 增大 → 表面电导 $\sigma$ 增大 → 漏电流 $I_D$ 增大
2. **多子起作用**：多子器件
3. **一种载流子**：单极器件（unipolar）
4. **输入阻抗高**：MOS中绝缘体 $> 10^9\ \Omega$
5. **电压控制器件**：通过 $V_{GS}$ 控制沟道电导和沟道电流

> **小结**：MOSFET通过栅极电压 $V_{GS}$ 控制栅下半导体表面的载流子浓度，当 $V_{GS} > V_T$ 时形成反型沟道，连通源漏，产生电流。这是一种电压控制型、单极型、多子器件，具有极高的输入阻抗。

## 10.3 MOSFET的分类与符号

### 10.3.1 分类方法

MOSFET有两种分类维度：

**按沟道导电类型分：**
- **N沟道（NMOS）**：衬底为p型，源漏为n⁺，载流子为电子
- **P沟道（PMOS）**：衬底为n型，源漏为p⁺，载流子为空穴

**按沟道初始状态分：**
- **增强型（Enhancement-mode）**：常关器件，$V_{GS} = 0$ 时无沟道，需加栅压才能导通
- **耗尽型（Depletion-mode）**：常开器件，$V_{GS} = 0$ 时已有沟道，需加栅压才能关断

### 10.3.2 NMOS与PMOS参数对比

| 参数 | NMOS | PMOS |
|------|------|------|
| 衬底 | p型 | n型 |
| 源/漏（S/D） | n⁺ | p⁺ |
| 载流子 | 电子 | 空穴 |
| $V_{DS}$ 极性 | + | − |
| $I_{DS}$ 方向 | D → S | S → D |
| 载流子运动方向 | S → D | S → D |
| 增强型 $V_T$ | + | − |
| 耗尽型 $V_T$ | − | + |

### 10.3.3 电路符号

- **NMOS增强型**：栅极箭头**指向**沟道（向内），衬底与源极相连
- **NMOS耗尽型**：栅极与沟道之间有实线连接
- **PMOS增强型**：栅极箭头**背离**沟道（向外）
- **PMOS耗尽型**：栅极与沟道之间有实线连接

> **小结**：MOSFET按沟道类型分N/P两种，按初始状态分增强/耗尽两种，共四种类型。NMOS和PMOS的电压极性和电流方向完全对称，载流子运动方向均为从源到漏。

## 10.4 MOSFET的电流-电压特性

### 10.4.1 转移特性曲线

**定义**：$V_{DS}$ 恒定时，$I_{DS} \sim V_{GS}$ 的关系曲线，反映栅源电压 $V_{GS}$ 对漏极电流 $I_{DS}$ 的**控制能力**。

四种MOSFET的转移特性：

| 类型 | 特征 |
|------|------|
| NMOS增强型（常关） | $V_{GS} > V_T$ 时 $I_{DS}$ 才开始增大，曲线不过原点 |
| NMOS耗尽型（常开） | $V_{GS} = 0$ 时已有电流，夹断电压 $V_P < 0$ |
| PMOS增强型（常关） | $V_{GS} < V_T$（$V_T < 0$）时导通，电流方向相反 |
| PMOS耗尽型（常开） | $V_{GS} = 0$ 时已有电流，夹断电压 $V_P > 0$ |

**判断增强/耗尽型的简便方法**：
- 增强型：转移特性曲线与y轴**无交点**（$V_{GS} = 0$ 时 $I_{DS} = 0$）
- 耗尽型：转移特性曲线与y轴**有交点**（$V_{GS} = 0$ 时 $I_{DS} \neq 0$）

### 10.4.2 输出特性曲线

**定义**：$V_{GS}$ 恒定且 $V_{GS} > V_T$ 时，$I_{DS} \sim V_{DS}$ 的关系曲线。以 $V_{GS}$ 为参变量得到不同 $V_{GS}$ 下的曲线族，即为MOSFET输出特性曲线。

#### 输出特性的四个区域

**① 线性区（OA段）**

$V_{DS}$ 很小时，漏极电位对沟道电势影响很小，沟道厚度分布均匀，可近似为一个**电阻**。漏极电流与漏源电压呈**线性关系**，电阻阻值受栅压控制。

**② 过渡区（AB段）**

随着 $V_{DS}$ 增大，漏极附近沟道电势升高，栅极和沟道的电压差缩小，衬底表面电子积累变弱，沟道电阻增大，**曲线逐渐下弯**。

> **线性区与过渡区统称为非饱和区**，有时也统称为线性区。

**③ 饱和区（BC段）**

当 $V_{DS} = V_{GS} - V_T$ 时，漏端的反型层电荷为零，沟道在漏端被**夹断**。定义**饱和漏源电压**：

$$V_{Dsat} = V_{GS} - V_T$$

$V_{DS} > V_{Dsat}$ 后，沟道夹断点左移，漏极电流 $I_D$ 几乎与 $V_{DS}$ 无关而保持常数 $I_{Dsat}$，趋于饱和，曲线为**水平直线**。

> **关于"夹断"的正确理解**：夹断是"夹而不断"，电流只是被限制而非截止。夹断点后面支撑电子的不是原来的P型区域，而是电压更高、更吸引电子的漏极及其空间电荷区。电子冲入空间电荷区后，相当于"准自由电子"被漏极快速收集。

**④ 击穿区（CD段）**

当 $V_{DS}$ 继续增大，空间电荷区持续扩张达到源极，源极的电子不再受沟道和栅压的控制，直接经空间电荷区高速到达漏极，漏结发生**雪崩击穿**（或漏源间发生**穿通**），$I_D$ 急剧增大。实际应用中应**避免击穿**。

#### 输出特性曲线族

将各条曲线的夹断点用虚线连接起来：
- 虚线**左侧**为非饱和区
- 虚线**右侧**为饱和区

### 10.4.3 PMOS与NMOS的对称性

PMOS的特性与NMOS相对称：
1. $V_{GS}$、$V_{DS}$ 的**极性**和 $I_D$ 的**方向**都相反
2. 沟道中可动**载流子类型**相反（电子 vs 空穴）
3. **增强型**（常关）和**耗尽型**（常开）的 $V_T$ 符号相反

**总结规律**：
- **NMOS**：特性曲线位于**第一象限**
- **PMOS**：特性曲线位于**第三象限**
- **增强型**：转移特性曲线与y轴**无交点**
- **耗尽型**：转移特性曲线与y轴**有交点**

### 小结

MOSFET的转移特性反映了栅压对漏极电流的控制能力，是判断器件类型（增强/耗尽、N沟道/P沟道）的直观依据。输出特性则展示了器件在不同工作区的行为——线性区近似电阻、饱和区电流恒定、击穿区电流急剧增大。PMOS与NMOS的特性完全对称，只是极性和载流子类型相反。

## 本章总结

本章围绕MOSFET展开，核心知识框架如下：

**1. MOSFET与MIS结构的联系与区别**
- MOSFET利用MIS结构的表面场效应作为控制回路
- 区别在于MOSFET增加了源漏之间的水平电流回路

**2. MOSFET的基本结构与工作原理**
- 基本结构：栅极(G)、源极(S)、漏极(D)、衬底(B)
- $V_{GS} > 0$ 且 $V_{GS} < V_T$：形成耗尽区，无沟道
- $V_{GS} > V_T$：强反型，形成导电沟道
- $V_{GS} > V_T$ 且 $V_{DS} > 0$：产生漏极电流

**3. MOSFET分类**
- 按沟道类型：N沟道 / P沟道
- 按初始状态：增强型（常关）/ 耗尽型（常开）

**4. MOSFET特性曲线**
- 转移特性（$V_{GS} \sim I_D$）：反映栅压对电流的控制
- 输出特性（$V_{DS} \sim I_D$）：分为线性区、过渡区、饱和区、击穿区
