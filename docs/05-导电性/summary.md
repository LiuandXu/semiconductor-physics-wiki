# 本章总结

### 核心物理量之间的关系

$$\text{散射机制} \xrightarrow{\text{影响}} \text{迁移率 } \mu \xrightarrow{\text{影响}} \text{电导率 } \sigma \text{ / 电阻率 } \rho$$

### 重要公式汇总

| 物理量 | 公式 |
|:---|:---|
| 电流密度 | $J = J_n + J_p = (nq\mu_n + pq\mu_p)E = \sigma E$ |
| 迁移率定义 | $\mu = \left\| \dfrac{v_d}{E} \right\|$ |
| 迁移率微观表达 | $\mu = \dfrac{q\tau}{m^*}$ |
| 电导率 | $\sigma = nq\mu_n + pq\mu_p = \dfrac{nq^2\tau_n}{m_n^*} + \dfrac{pq^2\tau_p}{m_p^*}$ |
| 电阻率 | $\rho = \dfrac{1}{nq\mu_n + pq\mu_p}$ |
| 迁移率与 $T$、$N_i$ 的关系 | $\mu = \dfrac{q}{m^*} \cdot \dfrac{1}{AT^{3/2} + BN_i/T^{3/2}}$ |
| 多种散射合成 | $\dfrac{1}{\mu} = \sum \dfrac{1}{\mu_i}$ |

### 散射机制总结

| 散射机构 | 散射概率 | 温度依赖性 |
|:---:|:---:|:---|
| 电离杂质散射 | $P_i \propto N_i T^{-3/2}$ | $T \uparrow$，散射减弱 |
| 声学波散射 | $P_s \propto T^{3/2}$ | $T \uparrow$，散射增强 |
| 光学波散射 | $P_o \propto \bar{n}_q$ | $T \uparrow$，散射增强 |

### 关键物理图像

1. **漂移运动**是载流子在电场下的定向运动，产生漂移电流
2. **散射**是阻碍载流子定向运动的根本原因，决定了迁移率的大小
3. **迁移率**反映载流子在电场中运动的难易程度，$\mu = q\tau/m^*$
4. **电导率**由载流子浓度和迁移率共同决定，$\sigma = nq\mu_n + pq\mu_p$
5. **电阻率**随温度和杂质浓度的变化是载流子浓度和迁移率竞争的结果
