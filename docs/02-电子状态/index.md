# 第二章 半导体中的电子状态

> 本章是半导体物理的基础章节，从晶体结构出发，逐步建立对半导体中电子行为的理解：先看原子如何排列成晶体，再看电子在这样的周期性结构中如何运动，最终形成能带理论。理解本章内容对后续学习载流子浓度、导电性等至关重要。

---

### 2.1.1 晶体的基本概念

**什么是半导体？** 半导体是一种导电能力介于导体和绝缘体之间的物质，其性质容易受到外界因素（光、热、磁等）以及微量元素含量变化的影响。

**晶体的特点：** 晶体具有规则的几何外形、固定的熔点（如 Si: 1420°C，Ge: 941°C），更本质的特征是组成原子/离子按照一定方式有规则地排列，具有长程有序性（在微米量级及以上保持有序排列）。

按照原子排列的有序程度，固体可以分为：

| 类型 | 特点 | 举例 |
|------|------|------|
| **单晶** | 整个体积内原子规则排列，长程有序 | 单晶硅、单晶锗 |
| **多晶** | 由许多小晶粒（粒径 $\geq \mu m$）堆积而成，晶粒内部有序，整体无规则取向 | 多晶硅、金属 |
| **非晶** | 无规则外形和固定熔点，仅在几个原子间距内短程有序 | 非晶硅、玻璃 |

> **理解笔记：** 半导体器件通常使用单晶材料，因为只有高度有序的晶体结构才能产生确定的能带，从而实现可控的导电行为。多晶和非晶材料虽然也有应用（如多晶硅薄膜晶体管），但性能通常不如单晶。


### 2.1.2 晶体的周期性

#### 理想晶体与点阵

**理想晶体**由全同的结构单元在空间中无限重复排列而成。结构单元可以是：
- **单个原子**（如 Cu、Fe 等简单晶体）
- **多个原子或分子**（如 NaCl 晶体）

为了数学上描述这种周期性，引入**点阵**的概念。选取三个**基矢** $\vec{a}$、$\vec{b}$、$\vec{c}$（基本平移矢量），空间中的任意格点位置可以表示为：

$$\vec{r}' = \vec{r} + u\vec{a} + v\vec{b} + w\vec{c}$$

其中 $u, v, w$ 为整数。所有满足此条件的点构成点阵。

> **核心公式：** 晶体结构 = 基元 + 空间点阵
>
> 每个格点上放一个基元（原子或原子团），在空间中重复排列就形成了晶体结构。

#### 原胞与惯用晶胞

- **原胞（Primitive Cell）**：由基矢 $\vec{a}, \vec{b}, \vec{c}$ 构成的最小体积重复单元，只含一个格点，体积最小。
- **惯用晶胞（Conventional Cell）**：为方便描述对称性而选取的较大重复单元，不一定是最小体积。例如，面心立方（FCC）的惯用晶胞是一个立方体，但其原胞是一个菱面体。

#### 7个晶系与14种布拉伐格子

根据基矢之间的关系（长度和夹角），晶体可分为 **7个晶系**：

| 晶系 | 基矢关系 | 角度关系 |
|------|---------|---------|
| 三斜 | $a \neq b \neq c$ | $\alpha \neq \beta \neq \gamma \neq 90°$ |
| 单斜 | $a \neq b \neq c$ | $\alpha = \gamma = 90°, \beta \neq 90°$ |
| 正交 | $a \neq b \neq c$ | $\alpha = \beta = \gamma = 90°$ |
| 四方 | $a = b \neq c$ | $\alpha = \beta = \gamma = 90°$ |
| 六方 | $a = b \neq c$ | $\alpha = \beta = 90°, \gamma = 120°$ |
| 三方 | $a = b = c$ | $\alpha = \beta = \gamma \neq 90°$ |
| 立方 | $a = b = c$ | $\alpha = \beta = \gamma = 90°$ |

在每个晶系中，考虑不同的格点分布（简单、体心、面心、底心），共形成 **14种布拉伐格子**。


> **注意：** 布拉伐格子不一定总是原胞。例如面心立方的惯用晶胞含4个格点，不是原胞。

#### 对称性

晶体结构在空间各个方向具有相等的对称性。基本的对称操作包括：

1. **n度旋转轴**：晶格绕某一固定轴旋转 $2\pi/n$，结构与自身重合
2. **镜像反射面**：晶格对某平面做镜像反射后，与自身重合
3. **n度旋转反演轴**：绕固定轴转动 $2\pi/n$，再对垂直该轴的平面做镜像反射后，与自身重合

#### 晶列、晶向与晶面

- **晶列**：点阵中所有格点位于一系列相互平行的直线上，这些直线称为晶列。
- **晶向**：从原点出发到某一格点的矢量 $\vec{R} = l_1\vec{a} + l_2\vec{b} + l_3\vec{c}$，其中 $l_1:l_2:l_3 = m:n:p$（互质整数比），用方括号标记为 $[mnp]$。
- **晶面**：点阵中所有格点位于一系列相互平行等距的平面上。
- **晶面指数（密勒指数）**：设晶面在三个基矢轴上的截距分别为 $a/h$、$b/k$、$c/l$，取截距倒数并化为互质整数，得到 $(hkl)$。

> **理解笔记：** 密勒指数 $(hkl)$ 表示一族平行的晶面，$\{hkl\}$ 表示等效晶面族（由于对称性等价的所有晶面）。在半导体工艺中，不同晶面的性质（如氧化速率、腐蚀速率）差异很大，因此晶面选择非常重要。例如 Si 的 (100) 面和 (111) 面在 MOS 工艺中各有优劣。

### 2.1.3 晶体的化学键

**化学键**是组成晶体的原子（离子）之间的结合力。理解化学键的关键在于**原子的负电性**（电负性）——原子对核外价电子束缚能力的强弱。

**负电性**的定义与电离能、亲和能的关系：

$$\text{负电性} = 0.18 \times (\text{电离能} + \text{亲和能}) \text{ (eV)}$$

**规律：**
- 同一周期：原子核对电子的吸引力随原子序数增加而增加，电负性增大
- 同一主族：原子半径增大，电子离核距离增加，电负性减小

#### 两种主要的晶体化学键

**离子键：**
- 形成条件：原子之间电负性差较大
- 机理：IA 族元素（低电负性，易失电子）+ VIIA 族元素（高电负性，易得电子）→ 电子完全转移 → 正负离子通过静电引力（库仑力）结合
- 举例：NaCl 晶体
- 离子晶体特点：结合力强，硬度大，熔点高

**共价键：**
- 形成条件：原子之间电负性差较小（或为零）
- 机理：两个同种原子（如 Si-Si）没有电负性差，不发生电子转移，而是各贡献一个价电子，形成一对自旋方向相反的**配对共价电子**。带正电的原子实与两原子间带负电的电子云之间形成结合力。
- 举例：Si 晶体、Ge 晶体
- 共价晶体特点：方向性强，饱和性

**总结规律：**
- 原子间负电性差越大 → 越趋向于**离子晶体**
- 原子间负电性差越小 → 越趋向于**共价晶体**
- 大多数半导体材料介于两者之间（混合键），如 III-V 族化合物（GaAs）和 II-VI 族化合物（ZnS）

### 2.1.4 典型的晶体结构

晶态半导体材料的晶格结构主要有三种：

#### 金刚石结构（Diamond Structure）
- **代表材料**：Si、Ge
- **结构特征**：只含一种元素原子，通过共价键结合
- 由两个面心立方（FCC）晶格沿空间对角线位移 $1/4$ 长度套构而成的复式格子
- 每个原子周围有4个最近邻原子，形成**正四面体**配位
- 配位数 = 4
- 晶胞中包含 **8个原子**（8个角原子 × 1/8 + 6个面心原子 × 1/2 + 4个内部原子 = 8）


#### 闪锌矿结构（Zinc Blende Structure）
- **代表材料**：III-V 族化合物，如 GaAs、InP
- **结构特征**：类似金刚石结构，但由**两种不同元素**的原子各自构成面心立方格子套构而成
- 两种原子之间通过共价键和离子键结合，**共价键占主导**
- 正四面体配位

#### 纤锌矿结构（Wurtzite Structure）
- **代表材料**：CdS、ZnS 等
- **结构特征**：类似闪锌矿结构，含两种元素原子，含共价键和离子键
- 与闪锌矿的区别：具有**六方对称性**而非立方对称性
- **离子键占主导**

> **小结（2.1 晶体结构）**
>
> 本节建立了描述晶体结构的完整框架：从宏观的晶体特点（长程有序、固定熔点），到微观的周期性描述（基矢、原胞、布拉伐格子），再到化学键的本质（电负性差异决定键型），最后落实到半导体常见的三种典型结构（金刚石、闪锌矿、纤锌矿）。掌握晶向指数和晶面指数（密勒指数）是后续理解半导体各向异性性质的基础。Si 和 Ge 采用金刚石结构，III-V 族化合物（如 GaAs）采用闪锌矿结构，这是半导体器件物理的出发点。
