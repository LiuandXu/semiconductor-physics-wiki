## 2.5 电子的有效质量


### 有效质量的推导

对于半导体，真正起作用的电子集中在能带底部（导带底）或能带顶部（价带顶）附近。因此只需掌握能带极值附近的 $E(k)$ 与 $k$ 的关系。

在能带极值点（设 $k=0$ 处），对 $E(k)$ 做泰勒展开：

$$E(k) = E(0) + \left(\frac{dE}{dk}\right)_{k=0} k + \frac{1}{2}\left(\frac{d^2E}{dk^2}\right)_{k=0} k^2 + \cdots$$

由于 $k=0$ 是极值点，一阶导数 $\left(\frac{dE}{dk}\right)_{k=0} = 0$，忽略高阶项后得到：

$$E(k) - E(0) = \frac{1}{2}\left(\frac{d^2E}{dk^2}\right)_{k=0} k^2$$

定义**有效质量** $m_n^*$：

$$\frac{1}{m_n^*} = \frac{1}{\hbar^2}\left(\frac{d^2E}{dk^2}\right)_{k=0}$$

则能带极值附近的 $E(k)$ 关系可写成与自由电子类似的形式：

$$E(k) - E(0) = \frac{\hbar^2 k^2}{2m_n^*}$$

### 有效质量的正负

- **能带底**（导带底）：$E(k) > E(0)$，曲率 $\frac{d^2E}{dk^2} > 0$，所以 $m_n^* > 0$（**正值**）
- **能带顶**（价带顶）：$E(k) < E(0)$，曲率 $\frac{d^2E}{dk^2} < 0$，所以 $m_n^* < 0$（**负值**）

**曲率与有效质量的关系：** $E(k)$ 曲线的曲率越大（越"尖锐"），有效质量越小；曲率越小（越"平坦"），有效质量越大。

### 有效质量的意义

#### 电子的速度

电子运动可看做波包的运动，波包的群速度就是电子的平均速度：

$$u = \frac{1}{\hbar}\frac{dE}{dk}$$

代入能带极值附近的 $E(k)$ 关系：

$$u = \frac{\hbar k}{m_n^*}$$

与自由电子速度 $u = \frac{\hbar k}{m_0}$ 的形式完全一致，只是将惯性质量 $m_0$ 替换为有效质量 $m_n^*$。

**速度的特征：**
- 在能带底或能带顶，电子速度为 0
- 能带中部电子速度最大
- $u(k) = -u(-k)$（奇对称）
- 外层电子共有化运动强，能带宽，电子速度更大

#### 电子的加速度

在外力 $f$ 作用下，可以推导出：

$$a = \frac{du}{dt} = \frac{1}{\hbar}\frac{d}{dt}\left(\frac{dE}{dk}\right) = \frac{1}{\hbar}\frac{d^2E}{dk^2} \cdot \frac{dk}{dt} = \frac{f}{\hbar^2}\frac{d^2E}{dk^2} = \frac{f}{m_n^*}$$

这正是**牛顿第二定律**的形式！

> **核心结论：** 若将半导体中的电子视为具有有效质量的粒子，其运动满足牛顿第二定律 $a = f/m_n^*$。有效质量概括了半导体内部势场对电子的作用，使得我们无需考虑复杂的内部势场，就能描述电子在外力下的运动。

#### 自由电子与半导体电子的完整对比

| 物理量 | 自由电子 | 半导体中电子 |
|--------|---------|-------------|
| 薛定谔方程 | $-\frac{\hbar^2}{2m_0}\frac{d^2\psi}{dx^2} = E\psi$ | $-\frac{\hbar^2}{2m_0}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi$ |
| 势场 | $V(x) = 0$ | $V(x) = V(x+sa)$（周期性） |
| 波函数 | 平面波 $\psi = Ae^{ikx}$ | 布洛赫波 $\psi_k = u_k(x)e^{ikx}$ |
| $E$-$k$ 关系 | $E = \frac{\hbar^2 k^2}{2m_0}$（连续） | $E(k)$ 不连续（有禁带） |
| 速度 | $u = \frac{\hbar k}{m_0}$ | $u = \frac{\hbar k}{m_n^*}$ |
| 加速度 | $a = \frac{f}{m_0}$ | $a = \frac{f}{m_n^*}$ |

### 有效质量的特点总结

1. 有效质量与重力无关，只是一个**等效质量**
2. 有效质量**不是常数**，在能带底/顶附近近似为常数
3. 能带底 $m_n^* > 0$；能带顶 $m_n^* < 0$；转折点处 $m_n^* \rightarrow \pm\infty$
4. **能带宽** → 有效质量小（外层电子）；**能带窄** → 有效质量大（内层电子）
5. 有效质量概括了半导体**内部势场**的作用（可通过实验测定）

> **小结（2.5 电子的有效质量）**
>
> 有效质量是半导体物理中最重要的概念之一。它的本质是：在周期性势场中，电子受到内部势场的作用被"吸收"进了有效质量中，使得我们可以用简单的牛顿力学框架来处理晶体中电子的运动问题。有效质量由 $E(k)$ 曲线的曲率决定：$1/m_n^* = (1/\hbar^2)(d^2E/dk^2)$。曲率大（能带尖锐）→ 有效质量小 → 电子更"灵活"；曲率小（能带平坦）→ 有效质量大 → 电子更"笨重"。
