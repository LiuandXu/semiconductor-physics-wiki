# 第十一章 异质结

### 异质结的概念与分类


**异质结**是指由**不同的半导体单晶材料**组成的结。与同质结（同一种材料、不同掺杂类型）不同，异质结的两侧材料在以下三个方面存在差异：

- **禁带宽度** $E_g$ 不同
- **电子亲和能** $\chi$ 不同
- **功函数** $W$ 不同

#### 异质结的分类

异质结可按两种方式分类：

**1. 按导电类型分：**
- **反型异质结**：导电类型相反、不同材料的半导体。例如 p-Ge / n-GaAs。
- **同型异质结**：导电类型相同、不同材料的半导体。例如 n-Ge / n-GaAs。

**2. 按过渡层厚度分：**
- **突变型异质结**：两种材料的过渡只在几个原子距离范围内，属于**纳米级**。
- **缓变型异质结**：两种材料的过渡在几个扩散长度范围内，属于**微米级**。

#### 命名规则

异质结的命名格式为"导电类型1-导电类型2 材料1-材料2"，例如：
- **n-pGe-GaAs**：n型Ge与p型GaAs形成的异质结
- **p-pSi-GaP**：p型Si与p型GaP形成的异质结

> **规则**：禁带宽度小的材料写在前面。

#### 常见半导体材料参数（室温）

| 材料 | 禁带宽度 $E_g$ (eV) | 电子亲和能 $\chi$ (eV) |
|------|---------------------|----------------------|
| Ge | 0.67 | 4.13 |
| Si | 1.12 | 4.01 |
| GaAs | 1.43 | 4.07 |
| GaP | 2.24 | 4.0 |
| InSb | 0.18 | 4.59 |
| InP | 1.35 | 4.4 |
| CdS | 2.41 | 4.79 |
| SiC | 2.2 | 4.0 |

#### 异质结的特点

**与同质结的相同点：** 当两种不同的半导体材料接触时，费米能级趋于一致，引起电荷转移，在界面附近形成**空间电荷区**和**内建电场**。

**与同质结的不同点：** 由于结两边材料不同，即**介电常数不同**，使异质结界面处**电场不连续**，形成电场突变。这导致界面附近的**能带也产生突变**，严重影响载流子的运动，使得异质结具有许多同质结所没有的特性。

> **小结**：异质结是由不同半导体单晶材料组成的结，按导电类型分为反型和同型，按过渡层厚度分为突变和缓变。其核心特征是界面处能带不连续（存在导带阶和价带阶），这是异质结诸多独特性能的物理根源。2000年诺贝尔物理学奖授予Alferov和Kroemer，正是表彰他们在半导体异质结领域的开创性工作。

### 异质结能带图的构建（Anderson模型）

#### 基本概念

在构建异质结能带图之前，先明确几个关键物理量。对于两种材料（下标1为禁带宽度小的材料，下标2为禁带宽度大的材料）：

- **电子亲和能**：$\chi_1$、$\chi_2$
- **禁带宽度**：$E_{g1}$、$E_{g2}$（$E_{g1} < E_{g2}$）
- **功函数**：$W_1$、$W_2$

两个最重要的量是**导带阶**和**价带阶**：

$$\Delta E_c = \chi_1 - \chi_2$$

$$\Delta E_v = (E_{g2} - E_{g1}) - (\chi_1 - \chi_2)$$

$$\Delta E_c + \Delta E_v = E_{g2} - E_{g1}$$

接触电势差：

$$qV_D = qV_{D1} + qV_{D2} = E_{F2} - E_{F1}$$

#### 突变反型异质结（pn型）能带图

以一个p型A材料和一个n型B材料形成的异质结为例。形成异质结后，n型费米能级较高，电子从n型流向p型，直到费米能级相等。

**能带图画法步骤：**

1. **先画统一费米能级**（平衡态下费米能级处处相等）
2. **画出两侧半导体中性区**的能带
3. **判断两侧空间电荷区载流子状态**，确定各自能带弯曲情况
4. **根据界面处 $\Delta E_c$、$\Delta E_v$ 保持不变**（相对位置不变），画出空间电荷区能带

**突变反型异质结能带图的关键特征：**

1. 内建电场使多子耗尽
2. 能带不连续，出现**尖峰**和**凹口**
3. 形成电子（p区少子）注入的**天然势垒**
4. 尖峰的相对高度取决于结两边的掺杂浓度

> **注意**：在反型异质结中，界面两边形成的都是**耗尽层**。

#### 突变同型异质结（nn型和pp型）能带图

对于nn型或pp型同型异质结，能带图的画法步骤相同。不同的是：
- **nn型**：一侧电子积累，另一侧电子耗尽
- **pp型**：一侧空穴积累，另一侧空穴耗尽

同型异质结中，界面两边一侧形成积累层、一侧形成耗尽层。


#### 实例：p-nGe-GaAs 能带图

已知参数：
- p-Ge：$E_{g1} = 0.67$ eV，$\chi_1 = 4.13$ eV
- n-GaAs：$E_{g2} = 1.43$ eV，$\chi_2 = 4.06$ eV

计算：

$$\Delta E_c = \chi_1 - \chi_2 = 4.13 - 4.06 = 0.07 \text{ eV}$$

$$\Delta E_v = (E_{g2} - E_{g1}) - \Delta E_c = (1.43 - 0.67) - 0.07 = 0.69 \text{ eV}$$

> **注意**：接触后公式仍然适用。

### 考虑界面态时的异质结能带图

#### 界面态的来源

界面态主要来源于两种材料的**晶格失配**。晶格常数差异越大，界面处的**悬挂键密度**越高：

| 异质结 | 晶格常数 ($10^{-10}$ m) | (111)面悬挂键密度 (cm$^{-2}$) | (110)面 | (100)面 |
|--------|------------------------|-------------------------------|---------|---------|
| Ge-GaAs | 5.6575 ~ 5.6531 | $1.2 \times 10^{12}$ | $1.4 \times 10^{12}$ | $2.0 \times 10^{12}$ |
| Ge-Si | 5.6575 ~ 5.4307 | $6.2 \times 10^{13}$ | $7.5 \times 10^{13}$ | $1.1 \times 10^{14}$ |

Ge-GaAs晶格匹配好，悬挂键密度低；Ge-Si晶格失配大，悬挂键密度高出一个数量级。

#### 界面态分类

- **施主型界面态**：被电子占据时呈电中性，电离后呈**正电性**，能够为半导体提供**电子**。
- **受主型界面态**：空着时呈电中性，电离后呈**负电性**，能够为半导体提供**空穴**。

#### 施主界面态的影响

当界面态为施主态，且态密度足够大时：
- 对于**n型半导体**：在半导体表面处形成**积累层**，层内电荷为电子，该层很薄。
- 对于**p型半导体**：在半导体表面处形成**耗尽层**，层内电荷为电离受主，该耗尽层很厚，其厚度由掺杂浓度决定。

> **规律**：施主态向结界面两侧同时提供电子，n型积累，p型耗尽，能带都**向下弯曲**。

#### 受主界面态的影响

当界面态为受主态，且态密度足够大时：
- 此时异质结界面两边的状态**完全由界面态电荷决定**，与功函数等没有关系。
- 对于**n型半导体**：形成很厚的耗尽层，层内电荷为电离施主。
- 对于**p型半导体**：形成积累层。

> **规律**：受主态向结界面两侧同时提供空穴，n型耗尽，p型积累，能带都**向上弯曲**。

> **小结**：界面态对异质结能带图有重大影响。当界面态密度足够大时，界面两侧的电学状态完全由界面态电荷类型决定，而不再由功函数差决定。施主型界面态使能带向下弯曲（n型积累、p型耗尽），受主型界面态使能带向上弯曲（n型耗尽、p型积累）。因此，在实际器件设计中，需要尽量选择晶格匹配的材料对来降低界面态密度。
