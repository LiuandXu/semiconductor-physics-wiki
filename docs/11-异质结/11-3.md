## 11.3 异质结激光器


### 半导体激光器基本原理

#### 三种跃迁过程

半导体激光器的发光涉及三种基本跃迁过程：

**1. 光吸收**
- 处于低能级 $E_1$ 的电子吸收能量为 $\hbar\omega_{12}$ 的光子，跃迁到高能级 $E_2$

**2. 自发辐射**
- 高能级 $E_2$ 的电子不稳定，即使没有外界作用，也会自动跃迁到基态 $E_1$
- 释放的能量转换为光子辐射出去
- 自发辐射的光子**相位不相同**，向各个方向传播，不是相干光

**3. 受激辐射**
- 当能量为 $\hbar\omega_{12}$ 的光子入射时，处于 $E_2$ 的电子受激跃迁到 $E_1$
- 发射出一个与入射光子**频率相同、相位相同、方向相同**的光子
- 一个光子入射，两个光子出射——这就是**光放大**

#### 粒子数反转

在热平衡状态下，低能级上的电子数总是多于高能级（玻尔兹曼分布），吸收占主导。要实现光的放大，必须实现**粒子数反转**——即高能级上的电子数多于低能级。

**粒子数反转的条件：**

在半导体中，粒子数反转表现为准费米能级的分裂。设 $E_{Fn}$ 为电子的准费米能级，$E_{Fp}$ 为空穴的准费米能级，则粒子数反转的必要条件为：

$$E_g \leq \hbar\omega_{12} < E_{Fn} - E_{Fp}$$

在粒子反转状态下，如果有能量为 $\hbar\omega_{12}$ 的光子束通过半导体，受激辐射占主导地位，系统发射的光子数将大于进入系统的光子数，这种现象称为**光量子放大**。

#### 实现粒子数反转的两个前提

**1. 直接带隙半导体**
- 导带最小值与价带最大值对应k空间中**同一位置**
- 电子跃迁不需要声子参与，确保电子-空穴复合时以**辐射光子**为主
- 例如：GaAs、InP等

**2. 电注入泵浦**
- 对pn结施加足够大的正向偏压
- 电子从N区注入、空穴从P区注入
- 大量非平衡载流子被限制在狭窄的**有源区**内

#### 半导体激光器的工作条件

1. **重掺杂**使得平衡时费米能级分别深入到p区价带及n区导带内
2. **正向电压**产生与内建电场相反方向的外加电场，pn结势垒降低，能带倾斜减小
3. 扩散增强：n区向p区注入电子，p区向n区注入空穴
4. 在有源区（分布反转区）内实现粒子数反转

### 双异质结激光器的优势

#### 同质结激光器的问题

同质结激光器的阈值电流密度约为 $5 \times 10^4$ A/cm$^2$，存在以下问题：
- 激光器**效率很低**
- 温度上升时，阈值电流**迅速增大**
- 只能用作用时间很短的**脉冲电流**来产生激光，以减少发热
- **不能实现室温连续工作**

#### 异质结激光器的优势

异质结激光器的阈值电流密度可低至约 $10^2$ A/cm$^2$，比同质结低了**两个数量级**。其优势在于：

1. **超注入效应**：利用异质结的超注入特性实现粒子数反转，注入效率远高于同质结
2. **载流子限制**：宽禁带材料形成势垒，将载流子限制在窄禁带的有源区内
3. **光限制**：窄禁带材料的折射率高于宽禁带材料，形成光波导结构，将光场限制在有源区
4. **室温连续工作**：由于阈值电流大幅降低，异质结激光器可以实现**室温连续工作**

#### 激光器的工作过程

1. 激活区内，大量非平衡载流子辐射复合
2. 一开始，非平衡电子-空穴对**自发复合**，引起自发辐射，发射光子
3. 自发辐射的光子相位不同，向各方向传播，大部分穿出激活区，对激光无贡献
4. 一小部分光子在pn结内传播，引起其他电子-空穴对**受激辐射**，产生更多光子
5. 受激辐射随注入电流增大而逐渐增多，逐渐趋于压倒优势
6. 利用半导体晶体的**解理面**形成两个平行反射镜面作为**谐振腔**，使光振荡、反馈，产生光的辐射放大，最终输出**激光**

> **小结**：半导体激光器的核心物理过程是受激辐射。实现激光输出需要三个基本条件：(1) 粒子数反转（通过电注入泵浦实现）；(2) 直接带隙半导体材料（确保辐射复合为主）；(3) 光学谐振腔（提供光的反馈和振荡放大）。异质结激光器利用超注入和载流子/光场双重限制效应，将阈值电流降低了两个数量级，实现了室温连续工作，这是半导体激光技术的重大突破。
